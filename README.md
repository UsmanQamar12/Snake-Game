# Snake-Game
 Snake Game built using programming language/framework used, e.g., JavaScript (HTML, CSS, JavaScript), etc. The game follows the classic arcade-style mechanics where the player controls a snake that moves around the screen, eats food to grow longer, and avoids colliding with itself or the screen boundaries. The objective is to survive as long as possible while achieving the highest score.

Features
✅ Classic snake movement using arrow keys
✅ Food spawning at random locations
✅ Score tracking system
✅ Collision detection (walls & self)
✅ Increasing difficulty as the snake grows
✅ Simple and interactive UI
